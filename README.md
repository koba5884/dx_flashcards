# デジタル社会・DX 4択クイズ

DXアドバイザー検定対策に最適な4択クイズ形式の学習アプリケーションです。

## デモ

https://koba5884.github.io/dx_flashcards/

## 概要

このアプリケーションは、デジタル社会やDX（デジタルトランスフォーメーション）に関する知識を効率的に学習できる4択クイズ形式の学習ツールです。カテゴリ別に整理された全116問の問題を、自分のペースで学習できます。

## 主な機能

- **4択クイズ形式**: 表面に問題と4つの選択肢、裏面に正解と解説を表示
- **カテゴリ別フィルター**: 学習したい分野に絞り込み可能（6カテゴリ）
- **ランダム出題**: ランダムに問題を表示して理解度をチェック
- **進捗表示**: 現在の学習位置を視覚的に確認
- **キーボード操作対応**: 矢印キーやスペースキーで操作可能
- **Google検索連携**: 各問題の詳細情報をすぐに検索可能
- **JSON形式の問題データ**: カテゴリ別に管理され、編集・追加が容易

## カテゴリ一覧（全116問）

- **デジタル社会・行政DX（17問）**: デジタル庁、デジタル社会形成基本法、行政サービスのデジタル化など
- **データ活用・法制度（17問）**: マイナンバー制度、個人情報保護法、データ活用の法規制など
- **ビジネス・DXフレームワーク（33問）**: DX推進指標、デジタルガバナンス・コード、BABOK、ビジネスモデルキャンバス、AI・データサイエンスなど
- **準公共分野DX（17問）**: GIGAスクール構想、医療DX、教育DX、防災DXなど
- **情報セキュリティ（16問）**: サイバーセキュリティ、フィッシング対策、暗号化技術など
- **DXリテラシー（20問）**: デジタイゼーション、RPA、クラウドサービス、データサイエンス基礎、AI・機械学習、ディープラーニングなど

## 使い方

### 基本操作

1. **問題の表示**: カード表面に問題と4つの選択肢が表示されます
2. **解答の確認**: カードをクリックすると裏返り、正解と解説が表示されます
3. **次の問題**: 「次へ →」ボタンまたは右矢印キーで次の問題へ
4. **前の問題**: 「← 前へ」ボタンまたは左矢印キーで前の問題へ
5. **ランダム**: 「ランダム」ボタンまたは「R」キーでランダムに問題を表示

### カテゴリフィルター

画面上部のカテゴリボタンをクリックすると、そのカテゴリの問題のみに絞り込まれます。

### キーボードショートカット

- `←` / `→`: 前後の問題に移動
- `Space` / `Enter`: カードを反転
- `R`: ランダムな問題を表示

### さらに調べる

カードの裏面（解答面）には「さらに調べる」ボタンがあり、クリックするとGoogle検索で関連情報を調べることができます。

## ローカルでの開発

ローカル環境で動作確認する場合は、簡易HTTPサーバーが必要です（JSONファイルの読み込みのため）。

### Python 3を使用する場合

```bash
cd /path/to/flashcards
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### Node.jsを使用する場合

```bash
cd /path/to/flashcards
npx serve
```

### VS Codeを使用する場合

Live Server拡張機能をインストールして、index.htmlを右クリック → "Open with Live Server"

## 問題の追加・編集

問題データは `data/` ディレクトリ内のJSONファイルで管理されています。

### 問題の形式

```json
{
  "category": "カテゴリ名",
  "question": "問題文",
  "choices": [
    "選択肢1",
    "選択肢2",
    "選択肢3",
    "選択肢4"
  ],
  "correctAnswer": 1,
  "explanation": "解説文",
  "searchKeywords": "検索キーワード"
}
```

- `correctAnswer`: 正解の選択肢のインデックス（0〜3）
- `searchKeywords`: 「さらに調べる」ボタンで使用される検索キーワード

### 新しい問題の追加方法

1. 該当するカテゴリのJSONファイルを開く
2. 配列の最後に新しい問題オブジェクトを追加
3. JSON構文が正しいことを確認（カンマの位置など）
4. ブラウザで動作確認

## NotebookLMを使った問題生成

このプロジェクトでは、Google NotebookLMとClaude Code skillsを組み合わせて、効率的に問題を生成しています。

### 問題生成のアプローチ

1. **NotebookLMへの資料アップロード**
   - DXアドバイザー検定の学習資料や公式ガイドをNotebookLMにアップロード
   - ソースに基づいた正確な回答が得られる環境を構築

2. **Claude Code skillsによる問い合わせ**
   - `notebooklm` skillを使用してNotebookLMに直接問い合わせ
   - 新しいカテゴリの提案や問題の生成を依頼

3. **20問ずつの生成**
   - NotebookLMのレート制限を考慮し、1回あたり20問ずつ生成
   - 選択肢の文字数バランス、解説の簡潔性などの要件を指定

4. **JSON形式への変換**
   - 生成された問題を本プロジェクトのJSON形式に変換
   - `index.html`に新カテゴリを追加してデプロイ

### 問題生成時の要件

NotebookLMに問題生成を依頼する際、以下の要件を満たすよう指定しています：

- カテゴリ名の統一
- 4つの選択肢（正答は1つ）
- 正答インデックスは0〜3
- 各問題に解説文を付与
- 検索キーワードを3つ程度付与
- **選択肢の文字数を均等に**（正答だけが極端に長くならないように）
- **正答の選択肢に詳細な解説を入れない**（簡潔に記述）

この方法により、高品質な問題を効率的に生成し、学習コンテンツを継続的に拡充しています。
