# デジタル社会・DX フラッシュカード

DXアドバイザー検定対策に最適な学習用フラッシュカードアプリケーションです。

## デモ

https://koba5884.github.io/dx_flashcards/

## 概要

このアプリケーションは、デジタル社会やDX（デジタルトランスフォーメーション）に関する知識を効率的に学習できるフラッシュカード形式の学習ツールです。カテゴリ別に整理された問題を、自分のペースで学習できます。

## 主な機能

- **フラッシュカード形式**: クリックで問題と解答を切り替え
- **カテゴリ別フィルター**: 学習したい分野に絞り込み可能
- **ランダム出題**: ランダムに問題を表示して理解度をチェック
- **進捗表示**: 現在の学習位置を視覚的に確認
- **キーボード操作対応**: 矢印キーやスペースキーで操作可能
- **Google検索連携**: 各問題の詳細情報をすぐに検索可能

## カテゴリ一覧

- **デジタル社会・行政DX**: デジタル庁、デジタル社会形成基本法、行政サービスのデジタル化など
- **データ活用・法制度**: マイナンバー制度、個人情報保護法、データ活用の法規制など
- **ビジネス・DXフレームワーク**: DX推進指標、デジタルガバナンス・コード、BABOK、ビジネスモデルキャンバスなど
- **準公共分野DX**: GIGAスクール構想、医療DX、教育DX、防災DXなど
- **情報セキュリティ**: サイバーセキュリティ、フィッシング対策、暗号化技術など

## 使い方

### 基本操作

1. **問題の表示**: カードをクリックすると裏返り、解答が表示されます
2. **次の問題**: 「次へ →」ボタンまたは右矢印キーで次の問題へ
3. **前の問題**: 「← 前へ」ボタンまたは左矢印キーで前の問題へ
4. **ランダム**: 「ランダム」ボタンまたは「R」キーでランダムに問題を表示

### カテゴリフィルター

画面上部のカテゴリボタンをクリックすると、そのカテゴリの問題のみに絞り込まれます。

### キーボードショートカット

- `←` / `→`: 前後の問題に移動
- `Space` / `Enter`: カードを反転
- `R`: ランダムな問題を表示

### 詳しく調べる

カードの裏面（解答面）には「詳しく調べる」ボタンがあり、クリックするとGoogle検索で関連情報を調べることができます。
