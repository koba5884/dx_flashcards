# デジタル社会・DX 4択クイズ

DXアドバイザー検定対策に最適な4択クイズ形式の学習アプリケーションです。

## デモ

https://koba5884.github.io/dx_flashcards/

## 概要

このアプリケーションは、デジタル社会やDX（デジタルトランスフォーメーション）に関する知識を効率的に学習できる4択クイズ形式の学習ツールです。カテゴリ別に整理された全100問の問題を、自分のペースで学習できます。

## 主な機能

- **4択クイズ形式**: 表面に問題と4つの選択肢、裏面に正解と解説を表示
- **カテゴリ別フィルター**: 学習したい分野に絞り込み可能（5カテゴリ）
- **ランダム出題**: ランダムに問題を表示して理解度をチェック
- **進捗表示**: 現在の学習位置を視覚的に確認
- **キーボード操作対応**: 矢印キーやスペースキーで操作可能
- **Google検索連携**: 各問題の詳細情報をすぐに検索可能
- **JSON形式の問題データ**: カテゴリ別に管理され、編集・追加が容易

## カテゴリ一覧（全100問）

- **デジタル社会・行政DX（17問）**: デジタル庁、デジタル社会形成基本法、行政サービスのデジタル化など
- **データ活用・法制度（17問）**: マイナンバー制度、個人情報保護法、データ活用の法規制など
- **ビジネス・DXフレームワーク（33問）**: DX推進指標、デジタルガバナンス・コード、BABOK、ビジネスモデルキャンバス、AI・データサイエンスなど
- **準公共分野DX（17問）**: GIGAスクール構想、医療DX、教育DX、防災DXなど
- **情報セキュリティ（16問）**: サイバーセキュリティ、フィッシング対策、暗号化技術など

## 使い方

### 基本操作

1. **問題の表示**: カード表面に問題と4つの選択肢が表示されます
2. **解答の確認**: カードをクリックすると裏返り、正解と解説が表示されます
3. **次の問題**: 「次へ →」ボタンまたは右矢印キーで次の問題へ
4. **前の問題**: 「← 前へ」ボタンまたは左矢印キーで前の問題へ
5. **ランダム**: 「ランダム」ボタンまたは「R」キーでランダムに問題を表示

### カテゴリフィルター

画面上部のカテゴリボタンをクリックすると、そのカテゴリの問題のみに絞り込まれます。

### キーボードショートカット

- `←` / `→`: 前後の問題に移動
- `Space` / `Enter`: カードを反転
- `R`: ランダムな問題を表示

### さらに調べる

カードの裏面（解答面）には「さらに調べる」ボタンがあり、クリックするとGoogle検索で関連情報を調べることができます。

## ローカルでの開発

ローカル環境で動作確認する場合は、簡易HTTPサーバーが必要です（JSONファイルの読み込みのため）。

### Python 3を使用する場合

```bash
cd /path/to/flashcards
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### Node.jsを使用する場合

```bash
cd /path/to/flashcards
npx serve
```

### VS Codeを使用する場合

Live Server拡張機能をインストールして、index.htmlを右クリック → "Open with Live Server"

## GitHub Pagesへのデプロイ

このアプリケーションは静的ファイルのみで構成されているため、GitHub Pagesで簡単に公開できます。

1. GitHubにリポジトリを作成
2. ファイルをプッシュ
3. Settings → Pages → Source で `main` ブランチを選択
4. 公開URLにアクセス

## 問題の追加・編集

問題データは `data/` ディレクトリ内のJSONファイルで管理されています。

### 問題の形式

```json
{
  "category": "カテゴリ名",
  "question": "問題文",
  "choices": [
    "選択肢1",
    "選択肢2",
    "選択肢3",
    "選択肢4"
  ],
  "correctAnswer": 1,
  "explanation": "解説文",
  "searchKeywords": "検索キーワード"
}
```

- `correctAnswer`: 正解の選択肢のインデックス（0〜3）
- `searchKeywords`: 「さらに調べる」ボタンで使用される検索キーワード

### 新しい問題の追加方法

1. 該当するカテゴリのJSONファイルを開く
2. 配列の最後に新しい問題オブジェクトを追加
3. JSON構文が正しいことを確認（カンマの位置など）
4. ブラウザで動作確認
